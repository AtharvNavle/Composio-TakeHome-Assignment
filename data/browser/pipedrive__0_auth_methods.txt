api need authentication. if you're creating an app continue to oauth 2.0 overview. you can find our step-by-step guide to getting oauth 2.0 implemented in your app in oauth authorization . if you're working with an api token integration the api token must be provided in the x-api-token header for all requests, for example: curl curl --request get \ --url "https://companydomain.pipedrive.com/api/v2/deals" \ --header "x-api-token: 659c9fddb16335e48cc67114694b52074e812e03" how to find the api token? 📘 keep in mind that an api token is tied to a specific user and company, giving access to all user's data. you can only have one active api token at any time. if you change the api token, all existing integrations using this api token will not be able to make successful requests against our api and stop working. updated 7 months ago read next custom fields did this page help you? yes no copy page if you're creating an app if you're working with an api
