Executive Patterns & Strategic Insights (The 100-App Horizon)
Key Findings
1. Auth Dominance & Migration Wave OAuth 2.0 (61%) and API Keys (70%) dominate. Legacy API keys are deprecating across major players (Zendesk sunsetting basic auth tokens by April 2027; HubSpot retiring static API keys for scoped Private App tokens).
2. Category Friction vs Velocity Developer & Infra (90%) and Communications (80%) have highest self-serve velocity. In contrast, Fintech & Enterprise CRM (DealCloud, Brex, PitchBook) gate API access behind corporate KYC or sales calls.
3. Integration Blockers & Quirks Most common friction points: Short token TTLs (DealCloud 15-min expiry), Non-standard auth headers (ClickUp raw string token, Harvest dual headers), and Enterprise partner gating (9/100 platforms).
4. Toolkit Implementation Pipeline 56 Day-1 Wins (Free tier + public REST/GraphQL); 21 Standard Sandboxes (14-30d trials); 14 Gated/Narrow Wrappers (App Review needed); 9 Blocked (Direct partnership required).
